# AgroFix 🛒 — Frontend

AgroFix is a modern grocery store web application built with **React**, **Tailwind CSS**, and **Material UI**. This is the **frontend** part of the full-stack project that connects to a backend powered by Node.js and PostgreSQL.

---

## 🚀 Features

- 🛒 Browse products
- ➕ Add to Cart / Remove from Cart
- 👤 JWT-based User Authentication
- 📦 Order Placement & Tracking
- 🛠️ Admin dashboard (Manage Products & Orders)
- 💅 Styled using Tailwind CSS and Material UI

---

## 📦 Tech Stack

- React
- React Context API
- Tailwind CSS
- Fetch API
- React Router
- JWT Authentication

---

## 🛠️ Getting Started

Follow these instructions to set up the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/agrofix-frontend.git
cd agrofix-Frontend
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Create .env File

Base_URL="http://localhost:5000/"

### 4. Start Development Server

npm run dev
